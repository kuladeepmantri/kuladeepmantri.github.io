# Project brain

This folder is the working memory of kuladeepmantri.com: what the site is, how it
is built, why it is built that way, what changed over time, and what is still
open. It is written for whoever picks the project up next (including future me),
so nothing has to be re-derived from scratch.

These are internal working docs. They are allowed to be blunt and unfinished.
The polished, public-facing writing lives on the site itself, not here.

## Older docs (still valid)

The pre-existing spec lives one level up in `docs/`:
- `docs/plan.md` — the original rebuild plan.
- `docs/design-language.md` — the visual/structural system and the checklist for a new project page.
- `docs/blueprints/<slug>.md` — one honest fact sheet per project.
- `docs/wiki/` — earlier decisions, palette, voice guide, the About story.

When those and this brain disagree, this brain is newer.
